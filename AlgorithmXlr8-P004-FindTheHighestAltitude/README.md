# Find the Highest Altitude

**Difficulty:** `Easy`

## Problem

A biker starts at altitude 0. Given an array gain, where gain[i] is the net altitude change between point i and point i+1, return the highest altitude reached along the whole trip.

Read n on the first line of standard input, then n space-separated integers on the second line. Print the highest altitude reached to standard output.

## Examples

### Example 1

**Input**
```
5
-5 1 5 0 -7
```
**Output**
```
1
```

**Explanation:** The altitudes visited are 0, -5, -4, 1, 1, -6, and the highest of these is 1.

### Example 2

**Input**
```
7
-4 -3 -2 -1 4 3 2
```
**Output**
```
0
```

**Explanation:** The altitude never rises above the starting point of 0.
