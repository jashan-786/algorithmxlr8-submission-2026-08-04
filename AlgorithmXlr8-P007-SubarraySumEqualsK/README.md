# Subarray Sum Equals K

**Difficulty:** `Medium`

## Problem

Given an array of integers nums and an integer k, return the total number of contiguous subarrays whose sum equals k.

Read n and k on the first line of standard input, then n space-separated integers on the second line. Print the count to standard output.

## Examples

### Example 1

**Input**
```
3 2
1 1 1
```
**Output**
```
2
```

**Explanation:** The subarrays [1,1] (first two) and [1,1] (last two) both sum to 2.

### Example 2

**Input**
```
3 3
1 2 3
```
**Output**
```
2
```

**Explanation:** The subarrays [1,2] and [3] both sum to 3.
