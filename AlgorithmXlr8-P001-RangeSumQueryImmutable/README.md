# Range Sum Query - Immutable

**Difficulty:** `Easy`

## Problem

Given an integer array nums, handle multiple queries of the form: calculate the sum of the elements of nums between indices left and right, inclusive.

Read n on the first line of standard input, then n space-separated integers on the second line, then q (the number of queries) on the third line, then q lines each with left and right. Print each query's sum on its own line.

## Examples

### Example 1

**Input**
```
6
-2 0 3 -5 2 -1
3
0 2
2 5
0 5
```
**Output**
```
1
-1
-3
```

**Explanation:** sumRange(0,2) = -2+0+3 = 1, sumRange(2,5) = 3-5+2-1 = -1, sumRange(0,5) = the total sum, -3.
