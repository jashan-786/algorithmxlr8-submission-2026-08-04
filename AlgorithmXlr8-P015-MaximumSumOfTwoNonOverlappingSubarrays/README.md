# Maximum Sum of Two Non-Overlapping Subarrays

**Difficulty:** `Medium`

## Problem

Given an integer array nums and two integers firstLen and secondLen, return the maximum sum of elements in two non-overlapping (not necessarily adjacent) contiguous subarrays, one of length exactly firstLen and one of length exactly secondLen. The two subarrays may appear in either order.

Read n, firstLen, and secondLen on the first line of standard input, then n space-separated integers on the second line. Print the maximum combined sum.

## Examples

### Example 1

**Input**
```
nums = [0,6,5,2,2,5,1,9,4], firstLen = 1, secondLen = 2
```
**Output**
```
20
```

**Explanation:** One length-1 window and one length-2 window, chosen to not overlap, giving the largest possible combined sum.

### Example 2

**Input**
```
nums = [3,8,1,3,2,1,8,9,0], firstLen = 3, secondLen = 2
```
**Output**
```
29
```

**Explanation:** The length-3 window [3,8,1] and the length-2 window [8,9] together give the best combined sum.
