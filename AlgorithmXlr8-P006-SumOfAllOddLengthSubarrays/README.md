# Sum of All Odd Length Subarrays

**Difficulty:** `Easy`

## Problem

Given an array of positive integers nums, return the sum of all possible odd-length subarrays of nums.

A subarray is a contiguous run of elements within the array.

Read n on the first line of standard input, then n space-separated integers on the second line. Print the total sum of all odd-length subarrays to standard output.

## Examples

### Example 1

**Input**
```
5
1 4 2 5 3
```
**Output**
```
58
```

**Explanation:** Adding up every odd-length subarray's sum (length 1, then length 3, then length 5) gives a total of 58.

### Example 2

**Input**
```
2
1 2
```
**Output**
```
3
```

**Explanation:** Only the two length-1 subarrays exist, summing to 1 + 2 = 3.

### Example 3

**Input**
```
3
10 11 12
```
**Output**
```
66
```

**Explanation:** The three length-1 subarrays and the one length-3 subarray together sum to 66.
