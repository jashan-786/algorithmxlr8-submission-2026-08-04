# Sum of Subarray Ranges

**Difficulty:** `Medium`

## Problem

Given an integer array nums, return the sum of all subarray ranges. The range of a subarray is the difference between its largest and smallest element.

Read n and the n values from standard input. Print the total sum.

## Examples

### Example 1

**Input**
```
3
1 2 3
```
**Output**
```
4
```

**Explanation:** Summing the range of all 6 subarrays gives 4.

### Example 2

**Input**
```
5
4 -2 -3 4 1
```
**Output**
```
59
```

**Explanation:** Summing the range of all 15 subarrays gives 59.
