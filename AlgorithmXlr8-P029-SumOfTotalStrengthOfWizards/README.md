# Sum of Total Strength of Wizards

**Difficulty:** `Hard`

## Problem

Given an array strength of wizard strengths, for every contiguous subarray, its total strength is (the weakest wizard's strength) times (the sum of the subarray). Return the sum of the total strengths of every contiguous subarray, modulo 10^9 + 7.

Read n and the n strengths from standard input. Print the sum, modulo 10^9 + 7.

## Examples

### Example 1

**Input**
```
4
1 3 1 2
```
**Output**
```
44
```

**Explanation:** Summing (min * sum) over all 10 subarrays gives 44.

### Example 2

**Input**
```
3
5 4 6
```
**Output**
```
213
```

**Explanation:** Summing (min * sum) over all 6 subarrays gives 213.
