# Count Number of Nice Subarrays

**Difficulty:** `Medium`

## Problem

Given an integer array nums and an integer k, return the number of "nice" subarrays, where a nice subarray is one containing exactly k odd numbers.

Read n and k on the first line of standard input, then n space-separated integers on the second line. Print the count.

## Examples

### Example 1

**Input**
```
nums = [1,1,2,1,1], k = 3
```
**Output**
```
2
```

**Explanation:** Exactly 2 subarrays contain 3 odd numbers each.

### Example 2

**Input**
```
nums = [2,2,2,1,2,2,1,2,2,2], k = 2
```
**Output**
```
16
```

**Explanation:** 16 subarrays contain exactly 2 odd numbers.
