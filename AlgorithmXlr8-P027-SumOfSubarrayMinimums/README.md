# Sum of Subarray Minimums

**Difficulty:** `Hard`

## Problem

Given an array of integers arr, find the sum of min(b) over every contiguous subarray b of arr. Since the answer may be large, return it modulo 10^9 + 7.

Read n and the n values from standard input. Print the sum, modulo 10^9 + 7.

## Examples

### Example 1

**Input**
```
4
3 1 2 4
```
**Output**
```
17
```

**Explanation:** Summing the minimum of all 10 subarrays gives 17.

### Example 2

**Input**
```
5
11 81 94 43 3
```
**Output**
```
444
```

**Explanation:** Summing the minimum of all 15 subarrays gives 444.
