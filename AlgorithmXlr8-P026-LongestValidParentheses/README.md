# Longest Valid Parentheses

**Difficulty:** `Hard`

## Problem

Given a string s containing just '(' and ')', find the length of the longest valid (well-formed) parentheses substring.

Read s from standard input. Print the length of the longest valid substring.

## Examples

### Example 1

**Input**
```
(()
```
**Output**
```
2
```

**Explanation:** The longest valid substring is "()", length 2.

### Example 2

**Input**
```
)()())
```
**Output**
```
4
```

**Explanation:** The longest valid substring is "()()", length 4.
