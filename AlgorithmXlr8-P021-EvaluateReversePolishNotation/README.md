# Evaluate Reverse Polish Notation

**Difficulty:** `Medium`

## Problem

Given an array of strings tokens representing an arithmetic expression in Reverse Polish Notation (postfix notation), evaluate it. Valid operators are +, -, *, /. Division between two integers truncates toward zero.

Read n and the n tokens (space-separated) from standard input. Print the final integer result.

## Examples

### Example 1

**Input**
```
5
2 1 + 3 *
```
**Output**
```
9
```

**Explanation:** ((2 + 1) * 3) = 9.

### Example 2

**Input**
```
5
4 13 5 / +
```
**Output**
```
6
```

**Explanation:** (4 + (13 / 5)) = 4 + 2 = 6 (division truncates toward zero).
