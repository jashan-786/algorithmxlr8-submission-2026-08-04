# Contiguous Array

**Difficulty:** `Medium`

## Problem

Given a binary array nums, containing only 0s and 1s, return the maximum length of a contiguous subarray that contains an equal number of 0s and 1s.

Read n on the first line of standard input, then n space-separated integers (each 0 or 1) on the second line. Print the maximum length to standard output.

## Examples

### Example 1

**Input**
```
2
0 1
```
**Output**
```
2
```

**Explanation:** The whole array itself has one 0 and one 1.

### Example 2

**Input**
```
3
0 1 0
```
**Output**
```
2
```

**Explanation:** The subarray [0,1] (or [1,0]) is the longest balanced one.

### Example 3

**Input**
```
4
0 1 0 1
```
**Output**
```
4
```

**Explanation:** The entire array is balanced, with two 0s and two 1s.
