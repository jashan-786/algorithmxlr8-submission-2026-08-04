# Score of Parentheses

**Difficulty:** `Medium`

## Problem

Given a balanced parentheses string s, return its score: "()" has score 1; "AB" (concatenation) has score A + B; "(A)" has score 2 * A.

Read s from standard input. Print the score.

## Examples

### Example 1

**Input**
```
(())
```
**Output**
```
2
```

**Explanation:** "()" inside scores 1, wrapped in one more pair doubles it to 2.

### Example 2

**Input**
```
(()(()))
```
**Output**
```
6
```

**Explanation:** Inner groups combine and double at each nesting level, totaling 6.
