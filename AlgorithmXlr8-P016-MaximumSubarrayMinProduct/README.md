# Maximum Subarray Min-Product

**Difficulty:** `Medium`

## Problem

The min-product of an array is its minimum element multiplied by its sum. Given an array nums of positive integers, find the maximum min-product of any non-empty contiguous subarray. Return the answer modulo 1,000,000,007.

Read n on the first line of standard input, then n space-separated integers on the second line. Print the answer.

## Examples

### Example 1

**Input**
```
nums = [1,2,3,2]
```
**Output**
```
14
```

**Explanation:** The subarray [2,3,2] has minimum 2 and sum 7, giving 14.

### Example 2

**Input**
```
nums = [2,3,3,1,2]
```
**Output**
```
18
```

**Explanation:** The subarray [3,3] has minimum 3 and sum 6, giving 18.
