# Product of Array Except Self

**Difficulty:** `Medium`

## Problem

Given an integer array nums, return an array answer such that answer[i] is equal to the product of all the elements of nums except nums[i].

You must write an algorithm that does not use the division operation.

Read n on the first line of standard input, then n space-separated integers on the second line. Print the resulting array, space-separated, to standard output.

## Examples

### Example 1

**Input**
```
4
1 2 3 4
```
**Output**
```
24 12 8 6
```

**Explanation:** answer[0] = 2*3*4 = 24, answer[1] = 1*3*4 = 12, and so on.

### Example 2

**Input**
```
5
-1 1 0 -3 3
```
**Output**
```
0 0 9 0 0
```

**Explanation:** Since exactly one element is 0, every position except the one holding that 0 becomes 0, and that position holds the product of everything else.
